# BM DIGITALS — Multi-page website prototype

Built with HTML5, CSS3 and vanilla JavaScript. No framework or database is required.

## Pages
- `index.html` — Home
- `about.html` — Company story, mission, vision, values and founder placeholder
- `services.html` — Service descriptions
- `solutions.html` — Exam Management System product concept
- `projects.html` — Portfolio placeholders
- `contact.html` — Contact details and enquiry form
- `privacy-policy.html` — Starter privacy notice
- `terms.html` — Starter terms and conditions
